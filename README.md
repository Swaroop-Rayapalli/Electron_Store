The Electronic Store is a modern e-commerce web application designed to sell electronic products such as smartphones, laptops, accessories, and home appliances. The platform provides a smooth and user-friendly shopping experience where customers can browse products, view detailed specifications, add items to their cart, and securely place orders.

The website features a responsive design for both desktop and mobile users, a structured product catalog with categories, and an intuitive checkout process. An admin dashboard allows store owners to manage products, inventory, and orders efficiently.

This project demonstrates modern web development practices including scalable architecture, responsive UI/UX design, and secure data handling for online retail platforms.
